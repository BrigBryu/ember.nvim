# ember.nvim v1.0.0

First stable release of the Neovim floating-window version of ember.

## Highlights

- Three scenes: `fire`, `lava`, and `spiral`
- Lightweight renderer optimizations with dirty-row updates and batched highlights
- Public API with `setup`, `start`, `stop`, `toggle`, `set_intensity`, `stats`, and `benchmark`
- Optional `nvim-tree` attach mode and palette customization support

## Notes

- Lava still looks a little odd, but it is interesting enough to keep as a scene.
- This repo ships as source only for plugin-manager installation.
- If you want the standalone terminal build, use the sibling `ember.term` repo.
