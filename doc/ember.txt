INTRODUCTION                                                  *ember.nvim-intro*

ember.nvim renders small animated ASCII heat-map scenes in a floating window
using only Neovim APIs. It is designed to stay out of the way during coding
sessions and to be scriptable from other plugins or configs.

==============================================================================
SETUP                                                          *ember.nvim-setup*

Lua example: >
  require("ember").setup({
    width = 33,
    height = 12,
    fps = 8,
    adaptive_fps = {
      enabled = false,
      idle_fps = 4,
      active_fps = 8,
    },
    full_rewrite_threshold = 0.6,
    scene = "fire",
    heat_levels = 11,
    char_ramp = { " ", ".", ":", "^", "*", "x", "#", "%", "@", "&" },
    wave = {
      enabled = true,
      style = "sway_breathe",
      amount = "subtle",
    },
    spiral = {
      turns = 1.85,
      thickness = 1.15,
      rotation_speed = 0.24,
      pulse_amount = 0.08,
      center_bias_x = 0,
      center_bias_y = 0,
    },
    attach = {
      mode = "nvim-tree",
    },
    palette = "auto",
  })
<

COMMANDS                                                    *ember.nvim-commands*

                                                        *:EmberStart*
:EmberStart    Start the fire animation

                                                        *:EmberStop*
:EmberStop     Stop the fire animation and close the window

                                                        *:EmberToggle*
:EmberToggle   Toggle the fire animation

                                                  *:EmberBenchmark*
:EmberBenchmark [frames]
               Run an offscreen benchmark and print average frame metrics

==============================================================================
API                                                              *ember.nvim-api*

                                                            *ember.setup()*
`require("ember").setup(opts)`
  Configure ember.nvim.

                                                            *ember.start()*
`require("ember").start(opts)`
  Start the fire animation. Optional `opts` override the current configuration.

                                                             *ember.stop()*
`require("ember").stop()`
  Stop the animation.

                                                           *ember.toggle()*
`require("ember").toggle(opts)`
  Toggle the animation on and off.

                                                    *ember.set_intensity()*
`require("ember").set_intensity(value)`
  Set fire intensity to a value between 0 and 1.

                                                        *ember.stats()*
`require("ember").stats()`
  Return cumulative runtime counters for frames, row rewrites,
  Neovim API usage, and render/write timing breakdowns.

                                                    *ember.benchmark()*
`require("ember").benchmark(opts)`
  Run an offscreen benchmark and return average frame timing, render/write
  timing breakdowns, dirty-row, and highlight batching metrics.

==============================================================================
CONFIGURATION                                                *ember.nvim-config*

Default values: >
  {
    width = 33,
    height = 12,
    fps = 8,
    adaptive_fps = {
      enabled = false,
      idle_fps = 4,
      active_fps = 8,
    },
    full_rewrite_threshold = 0.6,
    scene = "fire",
    zindex = 40,
    border = "none",
    row_offset = 1,
    col_offset = 0,
    intensity = 0.65,
    palette = "auto",
    heat_levels = 11,
    char_ramp = { " ", ".", ":", "^", "*", "x", "#", "%", "@", "&" },
    wave = {
      enabled = true,
      style = "sway_breathe",
      amount = "subtle",
    },
    spiral = {
      turns = 1.85,
      thickness = 1.15,
      rotation_speed = 0.24,
      pulse_amount = 0.08,
      center_bias_x = 0,
      center_bias_y = 0,
    },
    force_palette = false,
    attach = {
      mode = "nvim-tree",
      position = "bottom-left",
    },
  }
<

`attach.mode` supports:
  - `float`
  - `editor`
  - `nvim-tree`

When `attach.mode = "nvim-tree"` and the tree window is not available,
ember.nvim falls back to `float` mode.

`scene` supports:
  - `fire`
  - `spiral`

`wave` applies to the `fire` scene. `spiral` applies to the `spiral` scene and
controls the vortex turns, thickness, rotation speed, pulse amount, and center
offset.

`adaptive_fps` is optional and lowers the frame rate when ember is visually
quiet. `full_rewrite_threshold` controls when dirty-row updates give way to a
complete frame rewrite.

HIGHLIGHTS                                                *ember.nvim-highlights*

ember.nvim uses these highlight groups:
  - `EmberFire0`
  - `EmberFire1`
  - `EmberFire2`
  - `EmberFire3`
  - `EmberFire4`
  - `EmberFire5`
  - `EmberFire6`
  - `EmberFire7`
  - `EmberFire8`
  - `EmberFire9`
  - `EmberFire10`
  - `EmberFire11`

Themes and users may define these groups before setup to override ember.nvim
palette behavior. Set `force_palette = true` to reapply the configured palette
even when the highlight groups already exist.
